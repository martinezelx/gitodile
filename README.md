# GitOdile

**Git without the bite.** A friendly desktop Git client by
[@martinezelx](https://github.com/martinezelx).

This is GitOdile's public product hub for **issues, releases, downloads and
application-update feeds**. Application source, tests, builds and release
automation live in
[`martinezelx/gitodile-desktop`](https://github.com/martinezelx/gitodile-desktop).
This repository does not build or sign the application.

There is no qualified public installer yet. Windows x86-64 and Linux x86-64
remain behind the documented updater qualification and protected publication
gates; macOS is not published. Do not treat source archives generated by GitHub
for this repository as GitOdile application source.

## Downloads / Descargas

Tauri updater-signed Windows x86-64 NSIS installers, Linux x86-64 AppImages and their application-update files are attached to each [GitOdile release](https://github.com/martinezelx/gitodile/releases). Preview-testing releases may be public before installed-update qualification is complete; a prerelease label is not a qualification claim. Windows packages through 1.0.0 intentionally lack Authenticode and may show SmartScreen or unknown-publisher warnings. macOS is not yet qualified and no macOS package is published. Preview releases are marked as prereleases. Existing installers remain available for reinstall; a withdrawn update may stop appearing in the channel feed but is not silently replaced. [Application source](https://github.com/martinezelx/gitodile-desktop) is maintained separately and signing material is never published.

Los instaladores NSIS de Windows x86-64 firmados para el actualizador de Tauri, las AppImage para Linux x86-64 y sus archivos de actualización se adjuntan a cada [versión de GitOdile](https://github.com/martinezelx/gitodile/releases). Las versiones preview-testing pueden ser públicas antes de completar la cualificación de actualización instalada; la etiqueta preliminar no declara cualificación. Los paquetes de Windows hasta 1.0.0 carecen intencionadamente de Authenticode y pueden mostrar avisos de SmartScreen o de editor desconocido. macOS todavía no está cualificado y no se publica ningún paquete para macOS. Las versiones preview se marcan como preliminares. Los instaladores anteriores se conservan para reinstalar; una actualización retirada puede dejar de aparecer en el canal, pero no se sustituye silenciosamente. El [código de la aplicación](https://github.com/martinezelx/gitodile-desktop) se mantiene por separado y el material de firma nunca se publica.

## English

**A GitHub account is required to submit a report. Reports are public.** You can
review and edit the form before submitting it; opening it does not create an
issue.

### Report a bug

The best route is inside GitOdile: **More actions (⋯) → Report an issue**. The
app fills in the available app, operating-system, WebView and Git versions.
Project paths, source code and remote addresses are not included.

You can also [open the English bug form](https://github.com/martinezelx/gitodile/issues/new?template=bug.yml), or [request a feature](https://github.com/martinezelx/gitodile/issues/new?template=feature.yml).

Search existing issues first and never paste secrets, authenticated URLs or
code you are not free to share. Report vulnerabilities through the private
channel in [SECURITY.md](SECURITY.md), not a public issue.

## Español

**Necesitas una cuenta de GitHub para enviar un informe. Los informes son
públicos.** Puedes revisar el formulario antes de enviarlo; abrirlo no crea una
incidencia.

La mejor ruta está dentro de GitOdile: **Más acciones (⋯) → Reportar un
problema**. También puedes [abrir el formulario en español](https://github.com/martinezelx/gitodile/issues/new?template=bug-es.yml) o [proponer una mejora](https://github.com/martinezelx/gitodile/issues/new?template=feature-es.yml).

Busca primero y no incluyas secretos, direcciones autenticadas ni código que no
puedas compartir. Comunica las vulnerabilidades mediante el canal privado de
[SECURITY.md](SECURITY.md), nunca en una incidencia pública.
