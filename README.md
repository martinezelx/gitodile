# GitOdile — feedback

**Git without the bite.** GitOdile is a cross-platform desktop Git client that
turns version control into clear, worry-free steps.

This repository is the public issue tracker for GitOdile. The application's
source code is developed privately; everything here is about **reporting bugs
and requesting features**.

## Report a bug

The best way is from inside the app: **More actions (⋯) → Report an issue**.
GitOdile fills in your version, operating system, webview and Git version for
you, so the report starts with everything a maintainer needs.

You can also [open one here](https://github.com/martinezelx/gitodile-feedback/issues/new?template=bug.yml)
and paste that block yourself — **About → Copy system info** puts it on your
clipboard.

## Request a feature

[Open a feature request](https://github.com/martinezelx/gitodile-feedback/issues/new?template=feature.yml).
Describe the problem you ran into before the solution you have in mind: GitOdile
aims to translate what a person is trying to do into safe Git operations, so the
underlying goal is the useful part.

## Before you post

- **Search first.** Someone may have hit the same thing already.
- **Never paste secrets.** No access tokens, no authenticated remote URLs, and
  no source code you are not free to share. Issues here are public and
  permanently indexed.
- **Security vulnerabilities do not belong in public issues.** See
  [SECURITY.md](SECURITY.md) for the private reporting channel.

## What this repository is not

There is no source code here, and there are no pull requests to send. Issues,
their labels and their milestones are the whole content.
